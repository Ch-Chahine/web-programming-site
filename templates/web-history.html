Web History Timeline

1989 — World Wide Web Proposed

In 1989, Tim Berners-Lee was working at CERN when he proposed the idea of the World Wide Web. His idea was to use hypertext to connect information stored on different computers. This proposal became the starting point for the World Wide Web.

CERN — The Birth of the Web

1990 — Core Web Technologies and First Browser/Server

In 1990, Tim Berners-Lee developed HTML, HTTP and URLs, which became the main technologies of the Web. He also created the first web browser and web server at CERN. These technologies made it possible to create and access pages on the Web.

CERN — Web at 35

1991 — Web Becomes Available More Widely

In 1991, the World Wide Web started becoming available to people outside CERN. Tim Berners-Lee shared the Web project and its software with the wider Internet community. This helped more people start using and learning about the Web.

CERN — A Short History of the Web

1993 — Web Made Free and Mosaic

In 1993, CERN made the Web technology freely available for anyone to use. In the same year, NCSA released Mosaic, a web browser with a graphical interface. These events made the Web easier to use and helped it grow quickly.

CERN — 30 Years of a Free and Open Web NCSA — History of Mosaic

1994 — W3C Was Founded

In 1994, Tim Berners-Lee founded the World Wide Web Consortium, also known as W3C. Its purpose was to create common standards for the Web. These standards helped websites and web technologies work more consistently.

W3C — History

1995 — JavaScript Was Created

In 1995, Brendan Eich created JavaScript while working at Netscape. JavaScript made web pages more interactive instead of only showing static content. It became an important technology for creating interactive websites.

Computer History Museum — 1995 Timeline

1996 — CSS Level 1 Was Published

In 1996, W3C published CSS Level 1. CSS allowed developers to control the appearance of a web page separately from its HTML structure. This made designing and managing web pages easier.

W3C — CSS Level 1

Late 1990s — Commercialization of the Web Growth

During the late 1990s, the Web grew quickly and more people started using it. Businesses also began using websites for commercial purposes. The Web became an important tool for information, communication and business.

Computer History Museum — Networking and the Web

2000s — Growth of Web 2.0

During the 2000s, websites became more interactive and users started creating more of their own content. Blogs, wikis and social networking sites became popular. People were no longer only reading information on the Web, but also creating and sharing it.

Pew Research Center — Web 2.0

2014 — HTML5 Became a W3C Recommendation

In 2014, HTML5 became an official W3C Recommendation. It added and standardized features for modern websites, including better support for multimedia and semantic elements. HTML5 became an important standard for building modern web pages.

W3C — HTML5 Recommendation

2010s–2020s — Growth of HTTPS

HTTPS became more common as websites started using secure connections. It encrypts the communication between a web browser and a website. This helps protect information sent over the Web and makes browsing more secure.

Google Transparency Report — HTTPS

Key Web Technologies

HTML

HTML is the language used to structure content on web pages. It uses elements to organize things such as headings, paragraphs, links and other content. HTML is important because it gives a web page its basic structure.

W3C — HTML Intro

HTTP

HTTP is a protocol used to transfer information between a web browser and a web server. The browser sends a request and the server sends back a response. HTTP is important because it allows browsers and servers to communicate on the Web.

MDN — HTTP Overview

URL

A URL is the address of a resource on the Web. It tells the browser where a resource is located so it can access it. URLs are important because they give web pages and other resources their own addresses.

MDN — What is a URL?
