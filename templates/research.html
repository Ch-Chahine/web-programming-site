CSS At-Rules

What are CSS At-Rules?

CSS at-rules are special instructions that start with the @ symbol. They are used to control how CSS behaves in different situations. Some common examples are @media, @import and @keyframes.

MDN — CSS At-Rules

@media

The @media rule is used to apply CSS when certain conditions are met. It is commonly used to change the design depending on the screen size. This is useful when making a website responsive for phones, tablets and desktops. 

@media (min-width: 600px) {
    body {
        font-size: 18px;
    }
}
MDN — @media

@import

The @import rule is used to import styles from another stylesheet. It is normally placed near the beginning of a CSS file. 

@import url("other-style.css");
MDN — @import

@keyframes

The @keyframes rule is used when creating CSS animations. It defines the different steps that happen during the animation.

MDN — @keyframes

<button> vs <input type="button">

<button>

The button element creates a clickable button on a web page. The text is placed between the opening and closing button tags. It can also contain other HTML content, which makes it more flexible. 

<button type="button">Click Me</button>
MDN — Button Element

<input type="button">

An input with type="button" also creates a clickable button. Instead of placing the text between two tags, the text of the button is given using the value attribute. 

<input type="button" value="Click Me">
MDN — Input Button

Main Difference

Both can be used as buttons, but the button element is more flexible because it can contain HTML content. The input button uses its value attribute to display its text.

<datalist> vs <select>

<select>

The select element creates a menu containing different options. The user chooses an option from the choices provided in the menu. 

<select>
    <option>HTML</option>
    <option>CSS</option>
    <option>JavaScript</option>
</select>
MDN — Select Element

<datalist>

The datalist element provides suggested values for an input. The user can select one of the suggestions, but can also enter another value that is not included in the list. 

<input list="languages">

<datalist id="languages">
    <option value="HTML">
    <option value="CSS">
    <option value="JavaScript">
</datalist>
MDN — Datalist Element

Main Difference

A select gives the user a menu of options to choose from. A datalist gives suggestions for an input while still allowing the user to enter another valid value.

JavaScript, JScript and ECMAScript

JavaScript

JavaScript is a programming language commonly used on web pages. It can make a website more dynamic and interactive by allowing the page to react to different actions and events.

MDN — JavaScript

JScript

JScript was Microsoft's implementation of the ECMAScript language. It was mainly associated with older Microsoft web technologies such as Internet Explorer.

ECMAScript

ECMAScript is the standard that defines the JavaScript language. It provides rules and features that JavaScript implementations follow. JavaScript is therefore an implementation of the ECMAScript standard.

Ecma International — ECMAScript

Calling a JavaScript Function

After a JavaScript function is created, it does not run just because it was defined. The function can be called by writing its name followed by parentheses. 

function welcome() {
    console.log("Welcome");
}

welcome();

In this example, welcome() calls the function. If this line is reached while the script is loading, the function runs without the user needing to click a button.
