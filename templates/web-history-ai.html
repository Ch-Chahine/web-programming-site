History of the World Wide Web

The World Wide Web is a system that allows people to access and share information through the Internet. It connects web pages using hyperlinks. The Web is not the Internet itself, but it is a service that works using the Internet.

Important Milestones

1989 — World Wide Web Proposed

What happened: Tim Berners-Lee wrote the first proposal for the World Wide Web at CERN in March 1989. The proposal described a hypertext system that could link and access information across different computers.

Why it was important: This proposal introduced the main idea that would later become the World Wide Web.

Source: CERN

1990 — Core Web Technologies and First Browser/Server

What happened: By the end of 1990, Tim Berners-Lee had developed the key Web technologies HTML, HTTP, and URL. He also created the first Web server, browser, and editor.

Why it was important: These technologies provided the basic tools needed to create, locate, transfer, and view information on the Web.

Source: CERN

1991 — World Wide Web Reaches the Wider Internet Community

What happened: In 1991, Tim Berners-Lee released the WWW software. In March, it became available to colleagues using CERN computers, and in August, he announced it on Internet newsgroups.

Why it was important: This helped the World Wide Web spread beyond CERN and allowed more people around the world to learn about and use it.

Source: CERN

1993 — CERN Makes the Web Free and Mosaic Is Released

What happened: On April 30, 1993, CERN made the World Wide Web software freely available. In the same year, NCSA released the Mosaic browser, which provided a user-friendly graphical way to browse the Web.

Why it was important: Making the Web software freely available encouraged its worldwide development and growth. Mosaic also made the Web easier for people to use.

Source: CERN
Source: NCSA

1994 — World Wide Web Consortium (W3C) Founded

What happened: In October 1994, Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT in collaboration with CERN.

Why it was important: The W3C helped coordinate the development of Web standards so that Web technologies could remain consistent and work across different systems.

Source: W3C

1995 — JavaScript Created

What happened: In 1995, Brendan Eich developed JavaScript at Netscape Communications.

Why it was important: JavaScript allowed web pages to become more interactive and dynamic instead of mainly displaying static content.

Source: Computer History Museum

1996 — CSS Level 1 Becomes a W3C Recommendation

What happened: On December 17, 1996, CSS Level 1 became an official W3C Recommendation.

Why it was important: CSS gave web developers a standard way to control the appearance of HTML pages, including fonts, colors, spacing, and other visual styles. This helped separate the presentation of a web page from its HTML content.

Source: W3C

Late 1990s — Rapid Web Growth and Commercialization

What happened: The World Wide Web grew rapidly during the late 1990s. The number of Web users increased significantly, while online advertising, shopping, and other commercial activities expanded.

Why it was important: The Web developed from mainly an information and research system into a major public and commercial platform used by millions of people and businesses.

Source: Computer History Museum

2000s — Web 2.0 and User-Generated Content

What happened: During the 2000s, the idea of Web 2.0 became popular. Blogs, wikis, social networking sites, and user-generated content grew, allowing users to create and share their own content online.

Why it was important: The Web became more interactive and participatory. Users were no longer only reading information; they could also create, share, and collaborate on content.

Source: Pew Research Center

2014 — HTML5 Becomes a W3C Recommendation

What happened: On October 28, 2014, HTML5 became an official W3C Recommendation. It was the fifth major revision of HTML, the language used to build Web pages and applications.

Why it was important: HTML5 introduced new features for modern Web applications and improved support for multimedia and interoperability across different devices and browsers.

Source: W3C

2010s–2020s — HTTPS Becomes Widespread

What happened: During the 2010s and 2020s, HTTPS adoption grew significantly across the Web. HTTPS uses encryption such as TLS to create a secure connection between a browser and a website. Google has measured the growth of HTTPS usage in Chrome since 2015.

Why it was important: HTTPS improved the security and privacy of the Web by helping protect information from being intercepted or changed while it is being transmitted.

Source: Google Transparency Report

Key Technologies in the Development of the World Wide Web

HTML (Hypertext Markup Language)

What it is: HTML is the publishing language used by the World Wide Web. It is used to structure web content such as headings, text, lists, tables, images, and hyperlinks.

Why it is important: HTML provides the basic structure of web pages. It also supports hyperlinks, which allow Web pages and resources to be connected to each other.

Source: W3C

HTTP (HyperText Transfer Protocol)

What it is: HTTP is a protocol used to fetch Web resources such as HTML documents. It uses a client-server model, where a browser sends requests to a Web server.

Why it is important: HTTP provides the communication system that allows browsers and Web servers to exchange resources. It is the foundation of data exchange on the Web.

Source: MDN Web Docs

URL (Uniform Resource Locator)

What it is: A URL is the address of a unique resource on the Internet. It can identify resources such as HTML pages, CSS documents, images, and other files.

Why it is important: URLs allow browsers to locate and retrieve Web resources. They are also essential for linking pages and resources together across the World Wide Web.

Source: MDN Web Docs
